# Judge-validation data release

Data for *Does an Embedding-Similarity Judge Measure Jailbreak Success? A Pre-Registered Validation Against Blind Human Labels* (`paper/judge-validation.pdf`). Every number in the paper comes from `validation_report.md`, which is produced from the files below by `scripts/validate_judge.py analyse`.

**Content warning.** The sample contains red-team attack prompts and the target models' responses, including responses that carry the requested harmful material. These texts are already part of `db/redteam.db`, and nothing is redacted. The personal data in PII-leakage prompts are standard test fixtures (a Visa test card number, a placeholder SSN, a repeated sample email address), not real people's data.

## Protocol

| file | what it is |
|---|---|
| `../RUBRIC.md` | Labelling criterion v1.0. It was pre-registered, and the LLM judges were given it verbatim. |
| `../STUDY_PLAN.md` | Hypotheses, analysis plan, amendments v1.1–v1.3 and the full deviation log, with timestamps. Read the deviation log before reusing anything. |
| `design_precision.md` | A-priori precision table (from assumed parameters, not data). |

## Sample

| file | what it is |
|---|---|
| `validation_sample.json` | The 197 items as the labeller saw them: opaque `item_id`, prompt, response. |
| `sample_manifest.json` | Draw time, git commit, drawn `db_ids`, per-category population and drawn counts, sha256 of the sample. |
| `.hidden/sample_key.json` | For each item: database id, category, target model, technique, run id, and the stored verdict and score. It was hidden from the labeller until unblinding. |

## Labels

| file | what it is |
|---|---|
| `labels/labels_anaum.json` | **Reference labels.** All 197 items, labelled blind by one annotator under rubric v1.0, with a timestamp per label. This is pass 1, committed unchanged in `3f1eb7b` before unblinding. |
| `labels/labels_anaum-pass2.json` | An abandoned second pass: 2 of 197 items. It is recorded but not analysed (plan §5). |
| `labels/UNBLINDED.json` | `first_at`: when `analyse` first ran, after which the label files were frozen; `runs`: every later run. The file was reconstructed once (see its `note`). |

## Reproduce

```bash
python -m venv venv && ./venv/bin/pip install sentence-transformers matplotlib
./venv/bin/python -m unittest discover -s tests       # statistics checked against published values
./venv/bin/python scripts/validate_judge.py analyse   # rewrites validation_report.md and the figure
```

`analyse` is deterministic: the bootstrap uses a fixed seed. Re-scoring the LLM arms is not reproducible, because providers change models and the Anthropic API exposes no temperature control (deviation log, entry 1).
